# Captures

`synthetic_*.csv` are hand-authored fixtures derived from the worked examples
and message catalogue in Part 2 of
[`atlantic-v5-plan.md`](../../docs/atlantic-v5-plan.md),
generated by [`gen_synthetic_captures.py`](gen_synthetic_captures.py) (`uv run
python test/captures/gen_synthetic_captures.py`). Every CRC is cross-checked
by two independent CRC-16/MODBUS implementations before being written out.

They unblock CRC/Frame/FrameAssembler work (M1-M2) before any real hardware
capture exists. **They must never be used to produce or freeze
`*.expected.json` golden files** — M3's exit criterion requires decoded
values reviewed by a human against real hardware, which synthetic data
cannot satisfy. Real captures (once available) should not carry the
`synthetic_` prefix.
